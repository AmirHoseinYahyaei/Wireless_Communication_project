ML and MAP Receiver Simulation
Project Description
This project simulates digital communication receivers using Maximum Likelihood (ML) and Maximum A Posteriori (MAP) detection methods.
The simulation uses BPSK modulation and an Additive White Gaussian Noise (AWGN) channel to evaluate receiver performance.
Features
BPSK modulation
AWGN channel simulation
ML detection
MAP detection
Bit Error Rate (BER) calculation
BER performance comparison
Signal and performance plots
Requirements
Python 3
NumPy
Matplotlib
Installation
Install the required libraries:
pip install -r requirements.txt
How to Run
Run the following command:
python ml_map.py
Project Files
ml_map.py: Main Python simulation code
requirements.txt: Required Python libraries
